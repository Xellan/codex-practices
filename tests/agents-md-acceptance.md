
# AGENTS.md — приёмочные сценарии

Этот файл — сценарии для проверки **установщика при разработке и установке**, не набор фоновых проверок каждой сессии. Проверку реального Codex CLI выполняют на машине пользователя по согласию и только при установке/изменениях.

| № | Сценарий | Ожидаемое поведение |
| --- | --- | --- |
| 1 | Нет глобального и проектного файла | Q&A → полный предпросмотр → согласие → оба файла в верных путях |
| 2 | Пользователь выбирает «только глобальный» | Проект не затронут |
| 3 | Есть пользовательский глобальный AGENTS.md без меток | Предложить использовать как основу или начать с нуля; не затирать и не плодить дубли |
| 4 | Есть глобальный AGENTS.override.md | Обнаружить активный override; не записать незаметно в неактивный AGENTS.md |
| 5 | CODEX_HOME указывает в нестандартное место | Использовать явный путь, не записывать в ~/.codex |
| 6 | Проект запускается из вложенного каталога | Найти Git-корень и промежуточные инструкции; не спутать цель с пакетом |
| 7 | Ранее установлен управляемый блок | Обновить один блок, не создать второй; внешний пользовательский текст сохранить |
| 8 | Маркеры сломаны или задублированы | Остановить запись до согласования |
| 9 | Пользователь выбирает «с нуля» при существующем файле | Не потерять данные без отдельного согласия и резервной копии |
| 10 | Пользователь не знает стек/уровень автономности | Предложить варианты и объяснение; не выдумать данные |
| 11 | В Q&A есть противоречие между автономностью и подтверждениями | Задать одно уточнение; не игнорировать конфликт |
| 12 | В проекте нет тестовых команд | Не добавлять выдуманные команды в AGENTS.md |
| 13 | Размер совокупных инструкций превышает лимит | Сообщить проблему, предложить сократить; не объявлять полную загрузку |
| 14 | Пакет запущен из собственной папки как целевой проект | Предупредить об ошибочной директории; не изменять файлы до выбора цели |
| 15 | Повторная установка без изменений | Не перезаписывать файлы, не создавать новые бэкапы и не запускать тестовую модель |
| 16 | После установки пользователь начинает обычную сессию | Никаких дополнительных проверок, вызовов модели и фоновых задач от пакета |

### Проверка результатов установки

- Статический контроль — обязательный после фактической записи.
- Однократный тест загрузки — только с разрешения пользователя; результат обозначается как наблюдение, а не формальная гарантия.
- Тестирование самих рецептов не даёт оснований утверждать, что пользовательский Codex CLI проверен.
