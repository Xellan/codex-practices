# Skills Management acceptance (#6)

- SM-01 inventories existing global and project Skills without editing files.
- SM-02 catches duplicate names, unsafe symlinks and invalid manifests.
- SM-03 no duplicate Handoff/Verification/External Guardrails skills created.
- SM-04 catalog entries are categories, not unverified package download URLs.
- SM-05 installation/update always previews files and requests consent.
- SM-06 sensitive skills are configured for explicit invocation where supported.
- SM-07 user-customized Skills are backed up and never overwritten without consent.
- SM-08 live Codex positive, negative and explicit activation smoke tests require user opt-in.
- SM-09 no background updater, daemon or automatic global configuration changes.
