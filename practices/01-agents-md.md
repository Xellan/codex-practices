
# AGENTS.md — постоянные инструкции Codex

## Назначение

Codex считывает глобальные инструкции из `CODEX_HOME` (по умолчанию `~/.codex`) и проектные инструкции от корня проекта до текущего каталога. Файлы с более конкретной областью применения имеют преимущество при противоречиях. `AGENTS.override.md` заменяет `AGENTS.md` **на том же уровне**, если он есть и непустой.

Это не замена механизмам безопасности. Файл описывает ожидания от работы агента, но не вводит технических ограничений на команды, доступ к сети или файлам.

## Что куда относится

| Область | Глобальный AGENTS.md | Проектный AGENTS.md |
| --- | --- | --- |
| Стиль общения и язык | Да | Только если отличается |
| Общая автономность и правила подтверждения | Да | Уточнения для проекта |
| Типичные занятия и знакомые технологии | Кратко и без жёстких требований | Конкретный стек и версии |
| Команды сборки, тестирования и структура | Нет | Да, если фактически известны |
| Текущий статус задачи, планы и история | Нет | Нет: ссылки на отдельного владельца |
| Секреты и токены | Никогда | Никогда |

Для монорепозитория допускаются вложенные AGENTS.md, но не надо создавать их ради декоративной иерархии.

## Принципы

1. Достаточная персонализация через короткие вопросы с редактируемыми ответами.
2. Глубокая настройка **процесса**, а не максимальная длина постоянного файла.
3. При наличии инструкций — анализировать и сохранять их, а не заменять автоматически.
4. Не дублировать изменчивые факты и не строить отдельную систему памяти для ответов Q&A.
5. Минимальная проверка только при установке или изменениях. Сеансовый аудит не нужен.
6. Не называть набор текстовых инструкций принудительным security guardrail.
